# Layoffs Data Cleaning Project

This project follows a guided data cleaning process inspired by Alex The Analyst. 
It includes the original dataset (layoffs.csv) and a SQL script (project.sql) used 
to clean, standardize, and prepare the data in MySQL.

## Project Steps
1. Remove duplicates  
2. Standardize company names  
3. Handle NULL values  
4. Fix date formats  
5. Normalize columns  
6. Create helper tables to store cleaned data

## Files Included
- **layoffs.csv**: Original dataset  
- **project.sql**: MySQL script used to clean the data  
- **README.md**: Project description  

## Tools Used
- MySQL Workbench  
- SQL (data cleaning functions)  

## Purpose
This project demonstrates basic data cleaning skills, including filtering, 
sorting, grouping, updating values, and preparing data for analysis.
